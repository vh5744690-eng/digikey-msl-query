设置

本工具不需要我的服务器 —— 浏览器直接调用 DigiKey API。 所以你需要用自己的免费密钥：
  1. 前往 developer.digikey.com 用 DigiKey 账号登录
  2. 在 My Applications 里 Create Application（2-legged OAuth 不需要填 Redirect URI）
  3. 到 API Products / Subscriptions 订阅 Product Information API v4（不订阅会 401/403）
  4. 回到应用详情页复制 Client ID 与 Client Secret（Secret 只显示一次）
免费额度：每个 Client ID 每日 1000 次。

密钥保存在本机浏览器的 localStorage，不会上传到任何服务器。清除浏览器数据后需重新填写。
